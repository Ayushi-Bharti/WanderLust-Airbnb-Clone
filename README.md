# 🏡 WanderLust – Airbnb Clone

WanderLust is a full-stack property rental web application inspired by Airbnb. It allows users to explore property listings, view property details, and manage their own listings.

## 🚀 Features

- **User Authentication:** User signup and login functionality.
- **Property Listings:** Create, view, edit, and delete property listings.
- **Reviews:** Users can add and manage reviews.
- **Responsive UI:** User-friendly interface using Bootstrap.
- **Database Management:** Store listing, user, and review data using MongoDB.
- **Map Integration:** Display property locations using Mapbox.
- **Image Uploads:** Property image management using Cloudinary.

## ⚙️ Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Ayushi-Bharti/WanderLust-Airbnb-Clone.git
```

2. Open the project directory:

```bash
cd WanderLust-Airbnb-Clone
```

3. Install dependencies:

```bash
npm install
```

4. Create a `.env` file and configure the required environment variables for MongoDB, Cloudinary, Mapbox, and session configuration as required by the application.

5. Start the application:

```bash
node app.js
```

6. Open your browser and visit:

```text
http://localhost:8080
```

*Use the port configured in your app.js if it is different.*
